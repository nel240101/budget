BUGETUL MEU - cum o pui pe telefon
==================================
1. github.com -> cont gratuit -> New repository (ex: "buget"), Public.
2. "Add file" -> "Upload files" -> trage TOATE fisierele din arhiva asta
   (index.html, manifest.json, sw.js, cele 3 iconite) -> Commit changes.
3. Settings -> Pages -> Deploy from a branch -> main / (root) -> Save.
4. Dupa 1-2 minute: https://NUMELE-TAU.github.io/buget/
5. Pe telefon deschide linkul:
   - Android (Chrome): meniul ⋮ -> Instaleaza aplicatia
   - iPhone (Safari): Partajare -> Adauga pe ecranul principal
Dupa prima deschidere merge si fara internet.
Datele stau doar pe telefon - fa backup din Mai mult -> Setari.
